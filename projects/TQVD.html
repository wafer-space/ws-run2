GF180MCU Run 2

TinyQV - RISC-V SoC with HDMI output

TQVD · RISC-V and CPUs · ½ × ½ slot

Rendered from the layout at 2.5 µm per pixel. Layers: NwellDiffusionPolysiliconMetal 1Metal 2Metal 3Metal 4Metal 5Top metalPad openings

This version of TinyQV uses the new 3v3 standard cell library, 3v3 SRAM macros and the split voltage pads. Apart from that it is similar to the Run 1 TinyQV, but with additional scratch RAM, new HDMI/VGA text mode output support and a single 8-bit DAC.
