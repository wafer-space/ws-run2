This version of TinyQV uses the new 3v3 standard cell library, 3v3 SRAM macros and a single line of pads to allow more area with fewer pins. The extra space is used for 9.5kB of scratch RAM. It also has a USB CDC peripheral which should allow serial comms without an external UART.
