GF180MCU Run 2

3.3V SRAM test 2

OCD3 · Memory test chip · 1 × ½ slot

Rendered from the layout at 2.5 µm per pixel. Layers: NwellDiffusionPolysiliconMetal 1Metal 2Metal 3Metal 4Metal 5Top metalPad openings

A variant of the 3.3V SRAM test chip submitted for the first shuttle run.

This one has the new 64 byte SRAM block on it, which was designed to (maybe) fit in a single Tiny Tapeout tile.

It also has a new design of a 3.3V power-on-reset (PoR) block.
